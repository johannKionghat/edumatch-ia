Ce que chaque licence impose

Licence Ouverte v2.0 (Etalab)

Réutilisation libre, y compris commerciale, à condition de mentionner la source (auteur, date de dernière mise à jour). Elle couvre les données du MESR, de l'INSEE, de France Compétences et de France Travail.

ODbL v1.0 (Open Database License, odc-odbl)

Licence de l'ONISEP pour les jeux IDÉO. Elle impose le partage à l'identique de toute base de données dérivée qui les intègre et leur usage public : toute table dérivée publiée sous une interface accessible au public, comme celle-ci, doit rester sous ODbL et attribuer le producteur.
